# Genesis: Can Agent-Created Practices Improve Later Work?

An agent writes a careful note about how to avoid a mistake. Does the note help with the next task, or does it merely add another document to the pile?

Genesis is a **research hypothesis and proposed evidence framework** about agents creating maintenance practices that improve later work. No Genesis behavioral result is established by the sources inspected for this edition. This is not a software or seed release.

The question is practical: must every useful continuity practice be installed by a designer, or can an agent develop some of them while working within a supplied environment?

An index, checklist or record is not enough. A stronger case would show that the agent actually uses the practice later, that its behavior changes usefully, and that the benefit is worth the maintenance cost. Repeatedly producing impressive architecture prose would not establish that case.

## What the question does not assume

The model, its prior knowledge, tools, storage, task setup, feedback and operating boundaries are supplied. "Agent-created" describes a contribution within that environment, not invention from nothing or independence from external orchestration.

Nor is failure reduction the only objective. A system that avoids mistakes by doing almost nothing has not necessarily become more useful.
